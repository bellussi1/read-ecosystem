# KOReader Ecosystem website

Static bilingual project website. The application source is at https://github.com/bellussi1/koreader-ecosystem.

Serve locally with `python -m http.server 8000` from this directory. No build or JavaScript is required. GitHub Pages deploys the repository root via Actions. Screenshots show fictional data and are copied from the application repository.

The site is hosted under `/read-ecosystem/`. A project-level `robots.txt` cannot control robots for the `github.io` origin: crawler policy must be set at the origin root or via a custom domain. Search visibility and training permissions are separate; no opt-in to training is implied.

Before changing copy, verify feature status against the app README. Check accessibility manually with keyboard, screen reader, zoom and mobile devices in addition to automated audits.
