# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Readers using Calibre, Kindle and KOReader, and contributors who want to test and improve open-source reading tools.

## Product Purpose
Present KOReader Ecosystem, a Windows companion for managing a Calibre library, transferring books to Kindle and connecting KOReader progress with Hardcover.

## Capabilities and Constraints
The project is early. Individual Kindle transfers have been tested. The complete KOReader–Hardcover flow, batch transfers and sidecar recovery need physical-device validation. The Windows installer is unsigned. CSV import from Goodreads, StoryGraph and Maratona is reviewable; direct synchronization is not available. The site is static, bilingual, hosted on GitHub Pages, and must work without JavaScript.

## Evidence on Hand
The application screenshots in assets show fictional library data. Project source and releases are hosted at github.com/bellussi1/koreader-ecosystem.

## Accessibility & Inclusion
Aim for WCAG 2.2 AA, keyboard access, reduced motion, responsive design, Portuguese and English, and good performance.
