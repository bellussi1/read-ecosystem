Em construção.

Transferências individuais para Kindle foram testadas. O ciclo completo KOReader–Hardcover, transferências em lote e recuperação de sidecars ainda precisam de validação em dispositivo. O instalador para Windows não é assinado.

Perguntas frequentes

Preciso de uma conta no Hardcover?

Não para consultar e organizar sua biblioteca Calibre. Os recursos do Hardcover precisam de uma conta.

Sincroniza com Goodreads ou StoryGraph?

Ainda não diretamente. Há importação revisável por arquivos CSV para ambos.

Onde ficam meus livros?

Os livros continuam na biblioteca Calibre no seu computador.

O projeto é gratuito?

Sim. O KOReader Ecosystem é open source sob licença MIT.
